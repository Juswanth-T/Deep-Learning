# Deep Learning

A collection of Jupyter notebooks exploring foundational and advanced deep learning concepts — built as part of coursework assignments. Covers neural network architectures, optimization techniques, and applied tasks like image classification, machine translation, and image captioning.

## Notebooks

| Notebook | Description |
|---|---|
| `Image_Classification.ipynb` | CNN-based image classification pipeline |
| `googlenet.ipynb` | GoogLeNet (Inception) architecture implementation |
| `vggnet.ipynb` | VGGNet architecture implementation |
| `Stacked_Autoencoder.ipynb` | Stacked Autoencoder for unsupervised representation learning |
| `Machine_Translation.ipynb` | Sequence-to-sequence model for machine translation |
| `image_captioning_rnn_decoder.ipynb` | Image captioning using CNN encoder + RNN decoder |
| `image_captioning_lstm_decoder.ipynb` | Image captioning using CNN encoder + LSTM decoder |
| `Normalization.ipynb` | Comparison of batch, layer, and instance normalization |
| `Optimization_methods.ipynb` | SGD, Adam, RMSProp and other optimizer comparisons |
